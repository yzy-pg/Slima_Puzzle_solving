# Slima 关卡系统

## 一、打开地编

（1）打开 Unity 项目。

（2）选择 `Tools / Slima / 关卡编辑器`。

（3）地编默认读取 `Assets/_Game/Data/Levels/` 中的第一个关卡 JSON。

## 二、新建关卡

（1）点击顶部“新建”。

（2）保存到 `Assets/_Game/Data/Levels/`。

（3）输入关卡文件名，例如 `Level_02.json`。

（4）新关卡以当前 16×16 原型关卡为模板创建。

## 三、编辑地图

（1）“选择”：点击格子并在右侧查看或修改属性。

（2）“地块”：选择地面、墙、酸、热或冷，再点击格子绘制。

（3）“实体”：选择出生点、终点、颜料、机关或道具，再点击格子放置。

（4）“擦除”：将格子恢复为普通地面，并删除该格实体。

（5）一个格子目前只能放置一个实体。

## 四、方向

（1）`0`：上。

（2）`1`：右。

（3）`2`：下。

（4）`3`：左。

## 五、实体属性

（1）实例 ID：关卡内唯一名称，不得为空或重复。

（2）类型：实体的玩法类型。

（3）方向：光线、分裂和弹射方向。

（4）颜色成分：红、黄、蓝及其组合。

（5）连接 ID：机关与门的连接名称。

（6）数值：压力板所需压力等单个实体参数。

## 六、机关连接

（1）压力板、按钮或拉杆与门使用相同的连接 ID。

（2）示例：压力板连接 ID 为 `door_a`，对应门的连接 ID 也填写 `door_a`。

（3）一个连接 ID 可以被同组机关和门共同使用。

## 七、关卡必需内容

（1）普通出口关卡需要 1 个出生点和 1 个终点。

（2）出生点数量必须为 1。

（3）光学胜利条件需要至少 1 个发射器和 1 个接收器。

（4）接收器必须指定目标颜色。

（5）地图需要保留从出生区域到玩法区域的有效通路。

## 八、关卡规则

（1）胜利条件可以选择“到达终点”“激活全部接收器”或“两者都满足”。

（2）未勾选“覆盖”的数值继承全局配置。

（3）勾选“覆盖”后，该数值只在当前关卡生效。

（4）全局配置文件为 `Assets/_Game/Data/Configs/GlobalGameplayConfig.json`。

（5）关卡 JSON 中覆盖值为 `-1` 时表示继承全局配置。

## 九、保存、验证与试玩

（1）点击“验证”，检查关卡错误和警告。

（2）修复所有错误后点击“保存”。

（3）点击“保存并试玩”，地编会将当前关卡绑定到原型场景。

（4）进入原型场景后点击 Unity 的 Play 按钮。

（5）选择 `Tools / Slima / 验证所有关卡` 可以批量检查全部关卡。

## 十、游戏操作

（1）WASD 或方向键：移动。

（2）Tab：切换史莱姆。

（3）E：操作拉杆或传输管。

（4）F：融合相邻史莱姆。

（5）Z：撤回。

（6）R：重置关卡。

## 十一、灰盒识别

（1）起点和终点：青色、橙红色细杆。

（2）颜料：彩色球体。

（3）压力板、按钮和拉杆：圆盘。

（4）药水和药丸：胶囊体。

（5）普通、激光和弹射分裂器：方块。

（6）发射器和接收器：带方向标记或中心灯的低圆台。

## 十二、美术替换

（1）创建 `SlimaVisualCatalog` 资产。

（2）为地块、道具、机关和史莱姆指定对应 Prefab。

（3）将该资产赋给原型场景中的 `SlimaGameBootstrap`。

（4）更换 Prefab 不修改关卡数据和玩法逻辑。

## 十三、关卡文件与场景

（1）每个关卡是一份独立 JSON，不是一份独立 Unity 场景。

（2）“保存并试玩”会让原型场景使用当前选中的关卡。

（3）正式关卡选择、关卡列表和切关流程尚未制作。

（4）旧 `BlockMapEditor` 保留为静态体素搭建与美术预览工具；正式玩法关卡使用本系统的 JSON 数据。
