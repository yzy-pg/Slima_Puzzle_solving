# 灯的示例（Lamp · 像素风 · 1×1×1）

## 素材

| 文件 | 作用 |
|---|---|
| `Lamp/Lamp_panel.png` + `Lamp/Lamp_frame.png` | 方块 `Lamp`（64×64 像素画，自动包边；规格和地面/墙完全一样 = **1×1×1** ✓） |
| `Lab_Floor_07_Lit/` + `Lab_Floor_01_Lit/` | **提亮版地板**：把灯附近的地板刷成这个，就有"被灯照亮"的像素效果 ✓（不依赖实时光 ✓） |

灯的面板是三层硬边圆（外晕 → 灯体 → 灯芯）+ 金属底板 + 灯座 —— 全程无抗锯齿，遵循像素风格 ✓。贴图导入已设为 **Point / 无 Mipmap** ✓。

## 用法

1. **拿到方块**：重新打开地图编辑器场景（或跑一次 ② 烘场景 → ③ 加游戏根）→ 方块库里会出现 `Lamp` ✓
2. **刷上去**：`Lamp` 刷在**地板之上那一层**（和 Spawn/Exit 一样，别把地板顶掉 ✓）
3. **让它真的照亮周围（实时点光源）**：在 `BlockLibrary` 的 `Lamp` 定义里勾 **`emitLight`** ✓
   - `lightColor` 暖黄（例如 `(1.0, 0.86, 0.6)`）· `lightRange` 6~8 · `lightIntensity` 1 ~ 1.5 ✓
   - ⚠️ 实时光**只对受光材质有效** ✗：地形若还用 `BlockMap/BlockUnlit`（不受光）就看不到效果 ✓ → 换成 `Slima/Toon (Cel + Pixel)` 才会被照亮 ✓
   - 数量上限 32 盏（`BlockMapRuntimeSpawner.maxLights`）✓
4. **不依赖实时光的稳妥做法（像素风推荐 ✓）**：把灯周围一圈地板刷成 **`Lab_Floor_07_Lit`** 或 **`Lab_Floor_01_Lit`** ✓
   - 这是同一套地板贴图的**提亮 + 暖色**版本 ✓ → 即使使用不受光 shader，也有"被灯照亮"的观感 ✓
   - 想让别的方块也有提亮版：把它目录下的 `_panel/_frame` 复制一份、整体提亮约 1.34 倍即可 ✓

## 说明

- 这两种做法可以**同时用**：实时光负责"真的有光"，提亮贴图负责"像素风的亮斑" ✓
- 如果你的地板用的是 `Lab_Floor_02` 之类，按第 4 步的方法自己复制一份提亮版就行 ✓（命名成 `<原名>_Lit` ✓）
