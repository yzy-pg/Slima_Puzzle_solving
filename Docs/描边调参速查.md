# 描边调参速查（Slima 三渲二描边 · 重写版）

> 管线（五步）：**每组一张遮罩 → 只描外轮廓 → 剔除特殊物件 → 重采样 + 像素化**
> 核心文件：`Assets/_Game/Art/Shaders/SlimaOutlineComposite.shader`、`SlimaOutlineMask.shader`、`Assets/_Game/Scripts/Runtime/SlimaToonOutlineFeature.cs`

## 1. 结构（一图看懂）

```
① 保护遮罩   （主角等 → 任何线都不许画在这里）        BeforeRenderingOpaques
② 清晰遮罩   （特殊物件 → 不参与像素化）              BeforeRenderingOpaques
③ 每个分组：画该组遮罩 → 立刻用它描外轮廓              BeforeRenderingPostProcessing
④ 最后一步：重采样 + 像素化（清晰遮罩内除外）
```

要点：

- 遮罩语义统一：**1 = 背景，0 = 该组物体**；描边只画在「自己是背景 + 邻域有物体」处 → **天生只向外**
- 遮罩与合并在**同一个 pass 内** → 顺序不会乱；**每个 pass 独立材质**，遮罩**直接绑在材质上**（不走全局）
- 遮罩的 **G 通道存该几何的视线深度** → 用来判断「有没有被更近的东西挡住」
- 遮罩是 `ARGBHalf`（半浮点），所以 1 个世界单位的叠放差也能分辨

## 2. 参数

| 参数 | 作用 | 推荐 |
|---|---|---|
| `Outline Color` | 描边颜色（含 alpha） | 纯黑 |
| 每组 `Thickness` | 该组描边粗细，单位 **屏幕像素** | 地形 3，起点/出口 2，主角 3 |
| `Pixel Size` / `Pixelate Amount` | 最后一步的像素化 | 2 / 1 |
| `Crisp Specials` + `Crisp Name Filter` + `Crisp Dilate` | 哪些物件**保持清晰**（含它们外面的线），外扩多少像素 | 开 / `Spawn\|Exit\|Player\|Slime` / 3 |
| **`Protect Name Filter`** | 哪些物件**永远压住线条**（任何组都不画线）→ 保证角色清晰 | `Player\|Slime` |
| `Mask Groups` | 每个分组 = 一个「整体对象」；同组物体（跨区块、跨材质）合成一张遮罩 | 见下 |

**内置分组**（按名字识别，同名可覆盖）：`地面 _Floor` · `墙面 _Wall` · `起点 Spawn` · `出口 Exit` · `主角 Player|Slime`

过滤条件（材质名 / 物体名 / Layer）**设置了哪几个就要求同时满足**；名字支持 `|` 表示或，且**沿父子链匹配**。

## 3. 调试

| `Debug Mode` | 画面 |
|---|---|
| **0** | 正常 |
| **1** | **分组填色**：每组一个颜色（红地面/绿墙面/蓝起点/黄出口/紫主角）；**没被填色 = 没被任何组识别** |
| **2** | **遮罩读数**：红 = 物体，绿 = 背景（每组都会重画调试画面 → 只看得到**最后一组**；只看一组请把其它组 `Enabled` 取消勾选） |

`Debug Mode ≥ 1` 时 Console 会打「遮罩分组报告」：每组命中多少子网格 + 场景里用到的材质名。

## 4. 症状 → 修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 某类物体**没有线** | 该组没匹配到 | `Debug 1` 看它有没有颜色 → 改该组的 `Name Contains` / `Material Contains` / `Layer Mask` |
| 该显示的线**消失了** | 遮挡判定太严 | 调小 `SlimaOutlineComposite.shader` 里的 `0.002` |
| 线**穿透**了本该挡住它的物体 | 遮挡判定太松 | 调大（0.003 ~ 0.005） |
| 线**盖住主角** | —（已由保护遮罩解决 ✓） | 把主角名字片段加进 `Protect Name Filter` |
| 特殊物件被像素化糊掉 | — | 保持 `Crisp Specials` 开 + 名字在 `Crisp Name Filter` 里 |
| 完全没有线 | 分组为空 / `Thickness = 0` / Feature 没挂 | 看 Console 的「描边流程已就绪」+ `Debug 1` |
| 参数改了没反应 | 编辑的不是当前生效的 Renderer | 用菜单 `给 URP Renderer 装上全屏描边 Feature`，弹窗会报当前生效管线 |

## 5. 已知限制

- 遮罩只画「本组几何」→ 组内物体互相遮挡**不影响**轮廓（刻意设计：整片地面要合成一个整体）
- 用 `FindObjectsOfType<MeshRenderer>` 每 60 帧重扫渲染器；挂了 `SlimaOutlineIgnore` 的物体（含子物体）不参与遮罩
- 像素化是最后一步全屏处理：描边线本身是**清晰**的，只有被像素化的场景部分是块状的
