# 描边调参速查（Slima Toon Outline）

> 症状 → 该动哪个参数。绝大多数"描边不对"都能在 30 秒内解决。

## 0. 先确认 Feature 在跑

进 Play 后 Console 应出现：

```
[Slima] Toon Outline 已生效：… | 管线=URP-HighFidelity | 相机需要深度纹理=True/False
```

- 没有这行 → Feature 没挂上，或你编辑的不是当前生效的 Renderer
- 拖参数时还会打一条「全屏描边参数已更新」→ **没有 = 编辑错了 Renderer**

## 1. 两套描边，选一个

| 依据 | `Edge Source` | 依赖 | 特点 |
|---|---|---|---|
| **颜色/亮度落差** | **1（推荐）** | 什么都不依赖 ✓ | 稳、立刻可用；但会把**强明暗交界**（阴影边、贴图深浅块）也描上 |
| 深度落差 | 0 | 需要 `_CameraDepthTexture` 可用 | 更"准"：只在真正的前后关系断开处出线；深度没绑上时**完全不出线**（且调参无反应） |

> ⚠️ 改过 URP Asset 的 **Depth Texture** 开关后，**必须退出 Play 再进** —— 渲染管线是进 Play 时构建的，运行中改资产不会重建它。
> 判据：`Debug Mode = 1`（原始深度）**全黑** = 深度没绑上，此时只能用 `Edge Source = 1`。

## 2. 参数怎么调

| 参数 | 作用 | 推荐 |
|---|---|---|
| `Pixel Size` | 像素块大小（屏幕像素）。**建议取整数**（2/3/4），非整数会让格子宽窄不一 | **2** |
| `Pixelate Amount` | 0 = 不做像素化，只描边 | 1 |
| `Edge Source` | 描边依据（见上表） | **1** |
| `Color Threshold` | **颜色描边的核心阈值**：亮度差≥它才算一条边。越小线越多越脏 | **0.2 ~ 0.3** |
| `Outline Thickness` | 描边粗细（单位 = 像素块）。屏幕实际宽度 ≈ 它 × `Pixel Size` | 1 ~ 2（地形） |
| `Outline Color` | 描边颜色（含 alpha） | 纯黑 |

**地形材质的 `描边｜粗细` 必须设 0** ✓（那是物体反转壳描边，用在方块地形上会在方块棱上裂开）；角色/道具材质用 2~3 ✓。

## 3. 症状表

| 症状 | 原因 | 怎么修 |
|---|---|---|
| **满屏黑白噪点 / 天空被描成花** | 阈值太小，把渐变和贴图细节都判成边 | `Color Threshold` 调到 **0.2~0.3** |
| **所有带边缘的物体一起变黑** | 同上（阈值过小，且加粗会把已判定的边一起加宽） | 先调阈值，再调 `Outline Thickness` |
| 完全没线 | Feature 没跑 / `Outline Thickness = 0` / 深度模式但深度没绑上 | 看第 0 节 + 第 1 节 |
| 只有轮廓、方块之间的棱没线 | 阈值略高 | `Color Threshold` 调到 0.15 左右 |
| 线太粗、糊成一片 | 粗细过大（且它 ×`Pixel Size`） | `Outline Thickness` 降到 1，或 `Pixel Size` 降到 1 |
| 改了参数毫无反应 | 编辑的不是**当前生效**的那个 Renderer | 用一键安装菜单，弹窗会告诉你当前管线名 |
| Debug 1/3 全黑 | 深度纹理没绑上（改 URP Asset 后没重进 Play） | 退出 Play 重进；或先用 `Edge Source = 1` |

## 4. 调试模式（Debug Mode）

| 值 | 画面 | 用途 |
|---|---|---|
| 0 | 正常 | 最终效果 |
| 1 | 原始深度缓冲 | 全黑 = 深度纹理没绑上（描边一定不出线） |
| 2 | 「落差 / 阈值」染成红 | **红区 = 会被描边的像素**；拉 `Outline Thickness` 红区应变宽 |
| 3 | 线性眼深度灰度（白=近） | 看深度层次是否正常 |

## 5. 安装 / 排错入口

菜单 `Tools / Slima / 地图编辑器 / 给 URP Renderer 装上全屏描边 Feature`：

- 给所有 URP Renderer 装上 `Slima Toon Outline`（已装过会跳过）
- 打开所有 URP Asset 的 **Depth Texture**（深度描边需要）
- 弹窗里会显示 **★ 当前生效的管线名** —— 那才是你要编辑的 Renderer
