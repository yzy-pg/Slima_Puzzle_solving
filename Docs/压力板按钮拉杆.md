# 压力板、按钮与拉杆

所有控制机关的本体以灰色为底色，64×64 像素纹理使用 Point 采样、无 mipmap、无压缩。模型占地以世界编辑器 1 格 = 1 世界单位 = 64 纹理像素换算，尺寸指整块模型的总宽度，不是每边的留白。

| 机关 | 现有/新增 ID | 占地与材质 | 动画 |
|---|---|---|---|
| 大压力板 | `PressurePlateLarge_A` | 62/64 格，灰色厚钢板、黄黑警示边框、四角螺钉 | 顶板沿 Y 压缩到 35%，底座和边框固定 |
| 小压力板 | `Lab_PressurePlate`、`PressurePlateSmall_B` | 59/64 格，灰色塑料像素表面 | 顶板沿 Y 压缩到 35% |
| 拉杆 | `Lab_Lever`、`Lever_B` | 0.52 格方形金属底座、0.07 粗金属杆、0.10×0.24×0.10 灰色塑料握把 | 底部轴沿 X 从 -32° 转至 +32°，0.22 秒 |
| 方形按钮 | `Button_A`、`Button_B` | 0.48 格方形底座、灰色塑料按钮 | F 按下，沿 Y 压缩到 25%，信号持续 0.65 秒后回弹 |

压力板保留原有重量判断：小板需要重量 1，大板需要重量 2。按钮从相邻格使用 F，拉杆仍为持续开关。动画只改变美术部件，不改变通行判定或逻辑占格。按压部件的轴位于底部，按下与回弹期间轴位置不变。

地图编辑器使用现有 L 关联模式。机关与门加入同一组后，机关的顶板/握把按稳定机关编号分配颜色，门显示同组全部机关的颜色。单个机关对应整扇门的同色；多个机关按编号从门本地横向的负方向到正方向排列成等宽竖向色带。重复颜色按机关数量累加面积，例如绿、红、红对应左侧 1/3 绿和右侧 2/3 红。门开启时色带随门板向右平移，动画结束后隐藏。黄黑警示框、金属杆、底座不受关联染色影响。门的模型与动画见 [灰色金属推拉门](推拉门.md)。

未设置颜色且未关联的机关保持灰色。旧地图没有实例关联时继续沿用原 A/B 频道：同频道存在门时显示关联色；新地图使用显式分组。只解除某个实例的分组就移除其门色带。

## 地图编辑器 RGB 选色

1. 点击右上角 **RGB 颜色**，再左键点击地图中的门、压力板、按钮或拉杆。关联面板中也可切到 **RGB 颜色** 页。
2. 调整 R/G/B 滑块或输入 0–255 数值，下方色块和十六进制值显示待应用颜色。
3. 点击 **应用颜色**：机关单独换色，关联门的对应竖向色带同步变化；选择门换色会将其关联机关统一换成所选颜色。
4. **恢复默认** 清除自定义颜色。Ctrl+Z / Ctrl+Y 支持一次撤销或重做整个颜色操作；按 F5 保存地图。

地图 JSON 的每格 `mechanismColor` 保存六位 RGB 十六进制值，场景烘焙也保留颜色。颜色随物件移动，删除/替换后清除，撤销后恢复。旧地图没有此字段时沿用默认配色。

程序可修改机关颜色，门会立即同步：

```csharp
gameplay.SetMechanismColor(greenButtonCell, Color.green);
gameplay.SetMechanismColor(redPlateCell, Color.red);
```

以上运行时覆盖颜色按稳定机关编号保存于当前 `BlockGameplayController` 内，移动、视图重建和关卡重置后保持；重新加载关卡时需由程序重新设置。运行时覆盖优先于地图保存的颜色。程序也可调用 `world.SetMechanismColor(cell, color)` 保存单格颜色，或 `BlockLinkVisuals.SetEditorColor(world, cell, color)` 使用与 RGB 面板相同的门/机关同步及撤销规则。

生成菜单：`Tools / Slima / 机关 / 生成压力板按钮拉杆模型`。生成物为 `Assets/BlockMapEditor/Resources/BlockModels/Controls/` 中的七个 Prefab，以及 `Assets/_Game/Art/{Models,Materials,Textures}/Controls/` 下的 Mesh、材质和 PNG。展示场景为 `Assets/_Game/Scenes/ControlShowcase.unity`，预览为 `Docs/images/ControlModels.png`。批处理验证入口：`SlimaPuzzle.EditorTools.SlimaControlArtValidation.Run`。
