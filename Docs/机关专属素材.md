# 机关专属素材

压力板、方形按钮与拉杆的新模型、按压/拉动动画、门关联分色与程序换色接口，见 [压力板按钮拉杆](压力板按钮拉杆.md)。

切分机、光照发射器和光照接收器使用灰蓝金属、深色描边和像素高光，与现有实验室素材配色一致。四张机壳／光学 PNG 均为实际 64×64 像素，RGBA、Point 采样、Clamp、无压缩、无 mipmap。

模型源文件为 `Assets/_Game/Art/Models/Mechanisms/*.obj` 与配套 `.mtl`，Unity Prefab 使用同目录的 Mesh `.asset`。以米为单位，Y 向上，原点位于格子底面中心，本地 +Z 是发射方向，模型占地不超过 1×1。光学中心在 y=0.5，与现有光束对齐。贴图用于模型 UV。

Prefab 放在 `Assets/BlockMapEditor/Resources/BlockModels/Mechanisms/`，自动接入现有 ID：`Splitter`；可推动的 `Lab_Laser_01/02/03`；固定的 `EmitterWhiteWall/EmitterRedWall/EmitterBlueWall`；白光持续／永久接收器 `Lab_Laser_04/05`；`ReceiverRed_A/ReceiverBlue_A/ReceiverPurple_A`。固定与可推动发射器保持相同立方体轮廓，推移规则仍由原配置决定。白光永久接收器保持白光颜色，永久触发逻辑由原配置决定。

立方体的光学面边框、普通机壳面和发光区域分别使用材质，采用 `Slima/Toon (Cel + Pixel)`，三者组成同一立方体表面。顶面与普通侧面使用完整机壳贴图。`GameplayMechanismArt` 标记让表现脚本保留材质本色；激活时光学面发光加强，关闭／重置时恢复。发射方向用正面发射口和顶面箭头贴图表示，不叠加额外的立体标记。

Unity 菜单 **Tools / Slima / 机关 / 生成专属模型与64像素材质** 可以重新生成派生模型、材质和 Prefab；会覆盖这一组派生资产，手工修改请先复制为独立资产。原有 `Tools/BlockMapEditor/Resources/Lab_Laser_*/*_simple.png` 保留。

展示场景：`Assets/_Game/Scenes/MechanismShowcase.unity`。发射器和接收器预览：`Docs/images/MechanismModels.png`；切分机最新造型与动画见下文圆锯预览。批处理检查入口：`SlimaPuzzle.EditorTools.SlimaMechanismArtValidation.Run`，检查 12 个资源 ID、尺寸／UV／法线、64px 导入、48 个朝向与材质检查、激活后复原，并渲染实际玩法 Prefab。验证在独立副本中执行。

## 光学面发光效果

11 种发射器／接收器 Prefab 已添加 `GameplayOpticGlow`，复用 `_Lamp` 的 `BlockMapLampHalo`、共享材质与叠加光晕 Shader，无需 Bloom。发射器只在本地 +Z 正面有光晕；接收器只开启匹配光束实际入射侧的光晕、灯面自发光和照明，其他侧关闭。入射方向随地图朝向换算；从两侧同时收到匹配光束时只开启这两侧。光晕中心位于光学面前方 `0.02` 单位（本地高度 `0.5`），随地图朝向旋转，始终朝向实际渲染摄像机；背向摄像机的光学面隐藏光晕，保留不透明深度遮挡。

发射器的正面灯面自发光、光晕和实时聚光常亮；接收器未收到匹配光线时三者全部关闭，收到后仅开启受光侧。持续型接收器在光线移开后熄灭，永久型保留曾受光的侧面，存档保存这些侧面，关卡重置后恢复未受光状态。颜色使用机关的白、红、蓝、紫光学颜色。顶部箭头使用普通金属材质，不自发光。

光学照明使用实时 Spot Light，位置为对应朝向旋转后的 `(0,0.5,0.55)`，距离光学面仅 `0.05`；向下倾斜 `25°`，使地板光斑靠近机关。发射器范围 `5`、强度 `3.2`；接收器范围缩短为 `1.8`、强度 `1.6`，只在受光侧附近照明。外锥角均为 `120°`，内锥角为外锥角的 `60%`。光线向前下方照射，不会被自身灯光染亮顶面、普通侧面或背后地板。金属机壳采用按法线受光的附加灯光模式（`_ExtraLightMode=0`、`_LightWrap=0`），防止低于顶面的邻近光源从下方染亮顶部。灯面自发光强度默认 `1.6`；光晕直径 `0.65`、强度 `0.65`、朝摄像机偏移 `0.12`。这些参数可在 Prefab 的 `GameplayOpticGlow` 中调整。效果在进入 Play 或玩法视图初始化时生成，不添加碰撞体，重建时随机关清理。接收器的光学材质默认不自发光，运行时由受光状态控制。

三档 URP Renderer 使用 Forward+；`Slima/Toon` 同时兼容 Forward 与 Forward+ 的附加光循环及每盏灯的像素参数。避免接收器或发射器启用照明后，因 Forward 每物体 4／8 盏灯的限制而挤掉 `_Lamp` 环境灯。

预览：`Docs/images/OpticLight.png` 展示正面定向照明（左为激活的紫光接收器，右为蓝光发射器），`Docs/images/OpticGlow.png` 展示光学面光晕。验证入口：`SlimaPuzzle.EditorTools.SlimaOpticGlowValidation.Run`，检查 11 种机关 × 4 朝向、灯面／光晕／聚光开关和方向、顶部不使用发光材质、实际匹配与不匹配光线、移开光线后的持续／永久状态、重置、重复生成、原 `_Lamp` 配置兼容，以及实际 GPU 正面地板照明、顶面／侧面／背后无自身灯光、光晕墙体遮挡和背面遮挡。

`SlimaPuzzle.EditorTools.SlimaOpticLightingRegression.Run` 另做 Forward / Forward+ 多灯 GPU 对照及 `test-level 2-1` 实际受光回归，检查接收器亮起后环境灯仍开启并参与关卡照明。

## 切分机圆锯动画

切分机只有地板和圆锯两个部件，没有立柱、顶梁、支撑、安装架或外置状态灯。地板尺寸为 `0.94×0.11×0.94`，圆锯中心位于地板顶面，本地 `(0, 0.11, 0)`。锯片缩放从 `0.66` 放大至 `1.1`（约增大 67%），可见齿缘直径接近地板长度。锯片绕 Y 固定转 90°，其平面沿地板槽的本地 Z 轴方向；圆锯竖直，只显示上半圆，下半圆通过材质裁切隐藏。

原图为 `Assets/_Game/Art/Textures/Mechanisms/SplitterSaw/SplitterSaw_original_64.png`，由内置 imagegen 绘制。24 张 `SplitterSaw_00.png` 至 `SplitterSaw_23.png` 均为 64×64 透明 PNG，每帧直接从原图顺时针旋转 15°，使用最近邻采样，中心和画布大小固定。紫色标记与三条弧形槽帮助看出旋转。

`SplitterSawAnimation` 按 16 帧／秒循环切换 SpriteRenderer 的精灵，完整一圈 1.5 秒；锯片 Transform 不旋转。关闭再启用时从第 0 帧重新开始，暂停随游戏时间停止。Inspector 的 `Frames Per Second` 可调速度。

`Slima/Saw Sprite` 材质双面显示，透明处及圆锯下半圆裁切并写入深度。裁切以精灵帧 UV 中线为准，随物件位置和朝向保持半露效果。圆锯作为独立精灵部件保存在 `Splitter.prefab` 中；OBJ 只包含地板，不携带精灵动画。

只更新切分机：Unity 菜单 **Tools / Slima / 机关 / 更新切分机圆锯**。验证入口为 `SlimaPuzzle.EditorTools.SlimaSplitterSawValidation.Run`；检查帧顺序、循环、长时间间隔、重启、半露中心、竖直朝向和透明度，并渲染全部 24 帧。`SlimaPuzzle.EditorTools.SlimaMechanismArtValidation.RunSimplified` 另检查切分机仅有地板和锯片、11 种光学机关为单位立方体，及 48 个朝向与颜色检查。

原图旋转预览：`Docs/images/SplitterSawSprite.gif`。实际模型动画：`Docs/images/SplitterSawModel.gif`。

## 生成提示词

Output intended to be normalized to a true 64x64 PNG; make a visibly exact 64x64 pixel grid enlarged uniformly if needed. No rendered object, gradients, soft brushwork, labels, watermark.
