# 像素阶梯光照

本次采用「每盏 Unity Light 可选择像素 / 平滑光照」路径。主光、点光和聚光均支持；只影响 `Slima/Toon (Cel + Pixel)` 材质。提亮实时计算在模型表面，作为材质基础颜色、顶点色、环境光之后的颜色层，最后应用场景雾。它保留深度遮挡和描边，不是穿透模型的屏幕叠图，也不生成烘焙贴图。

## 使用

1. 选中有 `Light` 的对象，Add Component → **Slima Toon Light**，或菜单 **Tools / Slima / 光照 / 为选中 Light 添加光源模式**。
2. `Mode`：**Pixel** 为阶梯 + 边界噪波；**Smooth** 为连续光照。
3. `Override Material Settings` 关闭时，只覆盖模式，数值来自被照射材质。开启后，该灯单独设置段数、过渡宽度、世界像素大小、种子和亮度倍率。
4. Unity Light 自身的 Color、Intensity、Range、Spot Angle、Shadows 仍然有效。使用实时光源（Realtime）；本功能不读取 Lightmap。

三个 `Assets/Settings/*-Renderer.asset` 已安装 **Slima Toon Lighting**。以后新增 Renderer，可以通过 **Tools / Slima / 光照 / 安装光源模式到全部 URP Renderer** 安装。当前支持工程使用的 URP 14 **Forward** 渲染模式。

没有该组件、组件被禁用或所在相机没有安装 Feature 时，使用材质的「默认光源模式」和材质参数。光源重叠时按 URP 光源索引分别设置，互不替换。

## 材质参数

| Inspector 参数 | 含义 |
|---|---|
| 阶梯段数 `_Bands` | 默认 5，可调 2～8，计算时取整数 |
| 亮度 1～5 `_Band0`～`_Band4` | 默认 **0、0.25、0.5、0.75、1**，每档独立可调。段数不是 5 时，从这五个亮度控制点中插值取对应档位；需要递增阶梯时保持这些值递增 |
| 默认光源模式 `_LightingMode` | 没有单灯组件时采用 Pixel 或 Smooth |
| 输入黑点 / 白点 | 决定光照分段的输入范围，默认 0～1；白点应大于黑点 |
| 光照曲线指数 | 默认 1；增大让暗部面积增大，减小让亮部面积增大 |
| 量化前亮度倍率 | 调整亮度进入阶梯的位置，与 Light 强度一起生效 |
| 阴影影响 | 0 忽略阴影，1 完全使用光源阴影衰减 |
| 光照包裹 | 调整法线对受光的影响 |
| 额外光模式 | 0 按法线，1 按距离形成光斑；聚光角度、距离和阴影仍有效 |
| 阶梯过渡噪声强度 `_NoiseStrength` | 0 为硬边；1 的过渡宽度为一个输入档位。中间值只扩大每条边界的颗粒过渡区，不会给整层铺噪波 |
| 噪声格大小 `_NoiseWorldSize` | 固定世界单位尺寸，默认 0.06。地面与墙面各选主导表面投影，避免墙上出现长条噪波。单灯覆盖使用 `World Pixel Size` |
| 噪波种子 | 改变颗粒图案，不随时间闪烁 |
| 阴影色 / 受光色 / 环境色 | 调整最终颜色；保留既有材质配色 |
| 无主光时使用备用光 | 兼容旧空场景。需要只有点光或严格黑底时关闭 |

距离衰减、阴影衰减、Light 颜色亮度和强度全部**先计算，再量化**。量化后不再乘连续衰减。默认五档的输入边界为 0.2、0.4、0.6、0.8，边界两侧通过噪波点选择相邻亮度，单个点仍然是离散亮度。

Pixel 模式以世界原点和世界轴为固定网格，用 `floor(世界表面坐标 / 世界格大小)` 确定噪波格，再在该格中心计算距离与阴影，防止每个片元的连续衰减把一个方点切碎。像素图案不读取屏幕窗口、相机位置或时间；移动、旋转、缩放摄像机都不会改变同一世界位置的噪波格。透视下方格会随表面投影变形，缩放时屏幕中的大小也会变化，世界尺寸保持不变。模型贴图仍使用原有 UV；曲面按局部切平面近似，轮廓及面交界处仍正常裁切。

「黑 0 / 白 1」描述每盏灯归一化后的光照系数。模型贴图、顶点色、环境光、有色光、多灯叠加和雾仍影响最终画面。要检查纯灰度五档，可用白贴图 / 白基色 / 白顶点色、白光、黑阴影色、黑环境光，关闭场景环境光、雾与备用光，只留一盏灯。多盏灯的叠加结果可以超过 1，不强制整幅画面只有五种颜色。

## 画面调试

- 三渲二建议先试 `Bands=5`、过渡宽度 `0.35`、世界噪波格 `0.06` 单位（1 米方块每边约 16 格）。
- 本次三个 Renderer 的 **Slima Toon Outline / Pixelate Amount** 均设为 0，Balanced 的 Render Scale 从 0.459 恢复为 1，避免整屏像素化和低分辨率掩盖光照噪波；描边保留。恢复整屏像素化会再次使整个场景呈现台阶轮廓。提高 Balanced 分辨率增加渲染开销。
- Smooth 只取消这盏灯的阶梯和噪波，不改变贴图过滤与描边。密集地板图集使用 Bilinear，其他自动生成图集保留 Point。BlockMap 的顶点吸附默认关闭，实际 chunk 网格现在生成正常法线。
- URP Asset 的 Additional Lights 必须启用 **Per Pixel**。本工程 Performant 原先关闭额外光，已改为 Per Pixel。低画质增加了额外光计算，需按目标设备评估性能。
- URP Forward 的 Per Object Limit 限制同一 Renderer 受多少盏额外光影响；当前 Balanced 为 2，HighFidelity 为 8，Performant 为 4。大块合并网格有多盏灯时，可在对应 URP Asset 调整此数值。
- 旧 `_NoiseMaskInvert` 序列化字段保留但隐藏；边界噪波已由相邻档位自动限定，不再使用整灯范围的反转遮罩。
- 旧 `_NoiseSpace` 和 `_NoisePixelSize` 材质字段保留但隐藏且不参与计算，已有材质即使曾保存 Screen 值也统一采用世界采样。

## 验证

`SlimaPuzzle.Rendering.EditorTools.SlimaToonLightingValidation.Run` 可通过 Unity `-batchmode -executeMethod` 执行 GPU 回归验证。将屏幕片元还原到同一世界平面，检查每个世界格内亮度一致、摄像机平移/缩放/旋转后同一世界格亮度不变，以及材质/单灯世界尺寸、旧 Screen 参数失效。另检查五个离散档位、噪波只跨相邻档位、单灯平滑模式、单灯三档覆盖、禁用光源、主光强度和模式、同位置光源的独立模式，以及 Renderer 安装。测试只创建临时场景，不保存游戏场景。图像输出到 `Logs/ToonLighting/`，纯光照图另存 `Docs/images/PixelLightNoise.png`。
