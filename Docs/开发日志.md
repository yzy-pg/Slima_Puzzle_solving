（15）**路线定案：取消 2D 解谜路径。关卡 = 地图编辑器烘出来的场景，后续统一用三维素材。**

- 可玩关卡链路：3D 地图编辑器刷地形 + 刷 `Spawn` / `Exit` 标记 → 菜单 ② 把地图烘成场景（几何 + 碰撞体 + 数据按 id 持久化进场景）→ 菜单 ③ 把当前场景变成可玩关卡（`BlockMapGameRoot`：读标记、生成角色、架相机、走到终点通关）→ Play。角色是「3D 碰撞 + 固定 4 方向 / 90° 档位的格子跳」（`BlockMapGridWalker`）。
- 修复的 bug：① `BlockWorld` 的持久化镜像在编辑器态被 `OnBeforeSerialize` 清空（表现为"第一次能跑、第二次报没有起点终点"）；② 标记方块改为半透明且不参与烘焙；③ 画笔对逻辑物件强制单格（原先 3³/5³ 体刷会一次刷出 27 / 125 个起点终点）；④ `VisuallySolid` 不再把标记 / 交互方块当实心（否则邻居会剔出面留下空洞）；⑤ 出生点自动放置改为「画得最多的连通区域」。
