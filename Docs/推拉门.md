# 灰色金属推拉门

`Door` 和 `Door_B` 使用相同的灰色金属门板，保留原 A/B 信号频道及地图 L 分组关联规则。门板为 `0.96×1×0.14`，本地 +Z 为正面，底面原点与格子地板对齐。贴图是内置 imagegen 绘制的实际 64×64 PNG，Point 采样、Clamp、无 mipmap、无压缩。

关闭时门板保持本地原位，显示并阻挡通行／光束。收到开门信号后，门板在默认 `0.35` 秒内沿自身本地 +X（右侧）平移 `1.05`，动画结束后隐藏 Renderer；门根节点与逻辑占格保持原位。关门时立即重新显示门板，播放向左滑回的动画，结束后恢复关闭姿态。中途反向不会跳变，暂停跟随游戏时间，重置恢复关闭且可见。通行与光束阻挡仍按现有信号状态判断。

`BlockMapDoor.hinge` 保留原序列化字段名，但现在引用 `SlidingPanel`，不再是旋转铰链。旧 `openAngle` 字段仅为兼容旧场景保留，不参与动画。`SetOpen`、`Open`、`Close`、`Toggle` 接口继续可用；`Rotate90` 只改变门的摆放朝向。

灰色贴图保留螺钉、金属框、面板缝与右侧凹槽把手。关联染色继续乘在金属纹理上：未关联时保持原灰色，一组机关为整门同色，多组为等宽竖向色带，重复颜色累计宽度。色带随门板平移，不丢失纹理，也不随开关状态变白。

Match crisp chunky low-color pixel clusters of the existing game's 64px laboratory mechanical textures. Door is a single slab which slides to the RIGHT, not two hinged leaves. Keep middle panels neutral and legible when gameplay multiplies the texture by red/green/blue link colors and splits it into equal vertical color stripes. Exact regular pixel art logically designed on a 64x64 grid; uniformly enlarge if required. Flat front orthographic view, no perspective, no background beyond the square tile, no text, no arrows, no logos, no glow, no transparency, no soft gradients, no watermark.
